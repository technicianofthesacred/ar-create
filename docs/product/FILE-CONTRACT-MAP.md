## One shallow view, not a migration instruction

Invented names below describe a possible human-readable view. They are **proposed logical paths**, not existing files, an approved physical layout or twelve stage folders. Existing originals and journals stay in their current owners until a reviewed mapping and separate change authority exist.

```text
Library/
  Sun exposure — video reference.md       [S1: URL/provenance; transcript only if actually obtained]
  Tea — conversation.md                  [S2: original once]
  Sun exposure — personal reflection.md   [N1: personal note once]
Collections/
  Sun Exposure.md                         [C1: question, learning brief/history; links S1, N1]
  Tea.md                                  [C2: question/brief; links S2 and optionally S1]
Pieces/
  Sun exposure — article.md               [P1: independent wording/approval/edition]
  Sun exposure — carousel.md              [P2: independent slide wording/approval/edition]
  Sun exposure — private share.md         [reference to selected P1 edition; preparation only]
Projects/
  Outdoor visit.md                        [J1: optional links to C1, C2, P1, P2]
```

C1 can begin with “What would change my understanding of sun exposure?” and the author's own note; it need not create J1, P1 or P2. C2 can reuse S1 by reference without copying it. A selected passage names source UUID, exact source hash and locator/quote; a readable relative link is navigation, not the complete revision identity. “Supports,” “challenges,” “explores” and “used in” express different relationships; personal relevance is distinct from factual support. An AI suggestion is not an adopted belief. The private-share reference selects an expression/edition, never exposes Library by default and grants no sending permission.
