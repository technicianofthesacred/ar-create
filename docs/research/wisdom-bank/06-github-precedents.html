Open source projects that map ideas

Ten GitHub projects, with a link to each. Open the live ones first: the Philosophy Web and the nf-metro playground.

I read each project's README from a read only copy and ran nothing. I could not open any live site, so how a map looks or feels is not checked. Star counts are from GitHub on 11 November 2026.

The projects

1. The Philosophy Web (25 stars)

234 philosophers and 478 lines of influence in one picture. It says nobody is placed by hand. Hover lights a thinker's neighbours and fades the rest, and click opens a side panel with every connection in and out. Lines are solid for influenced, dashed for critiqued, dotted for responded to.

Borrow
Hover fade, a side panel listing every connection, three line styles. The source is plain text, one block per thinker.
Avoid
One field of 234 is its size. It does not say how it copes with thousands.
Open the live mapCode

2. nf-metro (74 stars)

Draws transit style maps from a short text file. Each route is a coloured line with stations. Made for software pipelines, not ideas. Tap a line in the legend to isolate it and zoom to it. It says its playground runs in the browser with no install.

Borrow
Isolate one line from the legend. Lines declared in plain text. A quick way to draw an invented pathway for a mock-up.
Avoid
Built for one flow left to right. Many lines through one stop is not its case, as far as the README shows.
Open the playgroundGalleryCode

3. map4sci (4 stars)

Research code for large graphs with semantic zoom. Every connection carries a level from 1 to 7, where lower means more important, so zooming out draws only the strongest.

Borrow
Give every connection a level. It matches your far, closer, closest idea.
Avoid
Research code. I found no live demo.
Code

4. Hyper-Knowledge (92 stars)

Builds graphs where one relation can join many things at once, with the source of each. One offline page with a whole structure view where each relation is a capsule around its members, and a reader that shows one relation at a time.

Borrow
Drawing a relation as a capsule around what it joins. Reading one relation at a time.
Avoid
It joins many things. It does not join a relation to another relation.
Open the docsCode

5. Eusebius (1 star)

A research environment with four ways in: time, place, relation, evidence. Its rule is no bare claims. Every claim carries a confidence, a basis, a status and a source it read. AI suggestions stay apart from verified facts until a human acts.

Borrow
Keeping proposals apart until a person decides. Its status file says a relation can target a claim.
Avoid
Young, and its 15 September status says nothing is marked verified yet. I did not read its schema.
Code

Borrow

Also seen, from search descriptions only: WebVOWL draws ontologies, and its README warns that its old web address now belongs to someone else. An Obsidian plugin, persistent graph, exists only to save node positions, so people dislike a graph that rearranges itself.

What these add

  • Levels on connections make a far view possible. map4sci puts it in the data, so the far view draws only the strongest connections.
  • Isolating one line is a real feature. nf-metro does it from the legend, and it is the transit picture's most useful move.
  • Hover fade and a side panel keep a big picture readable without hiding it.
  • The source is a short text file in four of these. That suits equal entrances for you and agents.
  • Provenance on every claim matches your exact words rule.
  • None draws a connection between connections. The closest are Hyper-Knowledge's capsules and Eusebius's relation that targets a claim.

What to test next
