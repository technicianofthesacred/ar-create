# 1 — Material

Intent agreed 13 October: an active place to bring material in, explore what is available, organize it and bring selected resources together. This is more than a record of what was already dropped.

## Work surface

Proposed: compact project collection with useful list/thumbnail views, visible resource groups and an in-place preview. A clear Add action supports files/folders where permitted, recordings, supplied transcripts, photos/videos, pasted text/links and personal notes. Browse connected folders or existing library material without copying it into a second library. Voice capture, if supported and permitted on the device, creates an ordinary original recording with a receipt.

Each item exposes the next applicable action: play, transcribe, review transcript, inspect a document, read a captured link, annotate, group or assign to a part/output. Batch applicable work. Show queued/running/failed/ready and original location/availability. Never show an uploaded file as transcribed merely because it was received.

## Creative decisions and AI

Adrian groups sessions, combines selected resources, adds why they matter, assigns opening/closing/context roles and chooses what an output can use. AI can suggest groups, titles for provisional filing and processing actions; it cannot invent a final angle before understanding the sources. Linking one item to several groups/outputs preserves one original identity. Personal reflection stays attributed, separate from outside evidence.

## Saved result and handoff

Durable originals, attachment/relationship records, processing jobs and scoped human context. Section2 opens the exact recording/transcript chain; Research receives an explicit selected set, not every file in the folder. Late additions identify possibly affected work without silently rewriting it. Dragging into a group changes membership, not the physical original's location unless that move is explicit.

## Acceptance

A synthetic multi-session project visibly groups multiple sessions with opening/closing context; add another resource, process it, organize it, select a subset and resume after switching stories. Interrupted imports, duplicates, unsupported types and offline originals have useful recovery. No mandatory reimport of existing material.
